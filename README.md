# Chapter IV — Exercise 00: Personal Portfolio

## Overview
This project is a responsive personal portfolio website built entirely from scratch using pure HTML5, CSS3, and modern JavaScript (ES6+). The objective is to construct an authentic digital presence without relying on external CSS frameworks, UI libraries, or templates.
